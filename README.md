# astrbot_plugin_dafeiyu_emotion

给 AstrBot 角色加一层**持久情感状态**：从已有长期记忆建立关系档案，在主人私聊里注入当前情感，并按小步反思更新好感、信任、安全感、心情和占有欲。

这不是模型微调。它不改变模型权重，也不改人格主体，只通过状态、记忆和提示词让表达慢慢变化。

## 功能

- 从 `livingmemory` 已有记忆生成关系档案和初始状态；
- 只对配置的 `owner_qq` 私聊生效，群聊和定时任务不训练；
- 每 N 轮主人私聊回复，后台分析一次互动，做**有上限的小步调整**；
- 心情每天向基线回落，好感和信任变化更慢；
- `/情感` 查看当前状态，`/情感原因` 查看最近触发，`/情感重置` 回到初始基线；
- 情感事件最多保留 30 条，状态保存在插件数据目录，不进 Git。

## 安装

1. 把本目录放进 AstrBot 的 `data/plugins/`（目录名保持 `astrbot_plugin_dafeiyu_emotion`）；
2. 在 AstrBot 插件配置里填 `owner_qq`；
3. 重启 AstrBot，或重载该插件；
4. 可选：已安装 `livingmemory` 时，首次私聊会读取其数据库生成关系档案；没有也能用默认档案。

## 配置

| 字段 | 说明 |
| --- | --- |
| `owner_qq` | 必填，唯一主人 QQ；其他账号不会触发状态注入/反思 |
| `enabled` | 是否启用，默认 true |
| `reflect_every` | 每多少轮回复反思一次，默认 6，建议 6–10 |
| `livingmemory_db` | 可选，自定义 livingmemory 数据库路径 |

## 命令

- `/情感`：自然语言 + 数值查看当前阶段、好感、信任、安全感、心情、精力；
- `/情感原因`：最近 5 条情感事件；
- `/情感重置`：回到 seed 时的基线，保留关系档案。

命令只在主人私聊里响应。

## 数据

状态文件在 AstrBot 数据目录：

```text
data/plugin_data/astrbot_plugin_dafeiyu_emotion/state.json
```

里面可能包含关系档案和私聊事件，**不要提交到公开仓库**。`.gitignore` 已排除 `state.json` 和本地配置。

## 设计边界

- 每轮变化有硬上限：好感/信任/安全感/占有欲每次最多 ±2，心情 ±8，精力 ±5；
- 心情会向基线回落，避免一次吵架后长期失真；
- 只有主人私聊会训练；群聊、cron 任务、其他人不参与；
- 不把数值直接说给聊天对象，也不要求对方用情绪来“喂”状态；
- 角色语气仍由人格提示词决定，本插件只提供情感上下文。

## 已知限制

- 第一版没有独立的每日深度总结；目前是每 N 轮反思 + 每日心情回落；
- 初次 seed 依赖当前聊天 provider；provider 未就绪时会用默认档案，等首次私聊再补；
- 如果角色本身有很强的人格提示词，情感状态只应作为语气细节，不应压过人格；
- 运行时会产生额外后台模型调用，频率由 `reflect_every` 控制。
